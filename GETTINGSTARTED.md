# Getting started

For the Linux/Proton fork, begin with the main [README](README.md). It documents:

- the validated Proton and Vortex launch paths;
- installation of the playable GitHub Actions artifact;
- the native ImGui controls and display picker;
- logs, troubleshooting, known limitations, and build artifacts.

The detailed implementation and diagnostic guide is
[docs/linux.md](docs/linux.md). The architecture and CEF decision records are
[docs/architecture.md](docs/architecture.md) and
[docs/cef-proton.md](docs/cef-proton.md).

For upstream build prerequisites and project-wide build instructions, use the
[official build guide](https://wiki.tiltedphoques.com/tilted-online/technical-documentation/build-guide).
