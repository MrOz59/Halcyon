# Halcyon Game Modes

Game modes are planned high-level server extensions for runtime quests, events, PvP rules, bounties, factions, economy, and community-specific gameplay.

The scripting runtime has not yet been selected formally. TypeScript is the leading candidate, inspired by SkyMP's separation between a native authoritative core and high-level gameplay logic.

No production game-mode API exists yet. Initial examples will be added only after the C++ authority, Context, and replication boundaries are specified.
