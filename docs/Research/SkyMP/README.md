# SkyMP Research

SkyMP is being studied as a source of server-architecture patterns and potentially reusable components.

Priority areas:

1. plugin-data parsing (`libespm` or equivalent);
2. server-side world state and entity representation;
3. persistent change forms;
4. replication relevance and neighborhood filtering;
5. property bindings;
6. TypeScript game-mode APIs;
7. controlled client commands;
8. Papyrus VM integration;
9. save-file parsing for one-time migration.

The SkyMP client, Skyrim Platform, Chromium UI stack, and launcher are not initial adoption targets.

Before code is copied or linked, the license of each SkyMP subproject MUST be reviewed independently.
