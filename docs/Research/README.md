# Technical Research

This directory contains investigations that support design decisions without being normative by themselves.

Research documents should distinguish:

- verified behavior;
- source-code observations;
- external documentation;
- assumptions;
- open questions;
- recommended experiments.

Initial research areas include Tilted Evolution, SkyMP, SKSE, Papyrus, plugin formats, Linux/Proton, CEF, TrueHUD, and dynamic-form frameworks.
