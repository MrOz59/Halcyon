# Architecture Decision Records

Architecture Decision Records (ADRs) preserve important technical decisions and their consequences.

## Status values

- Proposed
- Accepted
- Deprecated
- Superseded

## Naming

```text
NNNN-short-decision-name.md
```

## Required sections

- Context
- Decision
- Consequences
- Alternatives considered
- References

Accepted ADRs should be reflected in the HTDS.
