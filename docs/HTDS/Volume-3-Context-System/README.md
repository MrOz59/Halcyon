# HTDS Volume 3 — Context System

Volume 3 defines Halcyon's Context architecture.

Contexts are the primary mechanism used to isolate incompatible state while preserving a shared multiplayer world.

The documents in this volume remain conceptual and are expected to change after the first Context-aware replication prototype.
