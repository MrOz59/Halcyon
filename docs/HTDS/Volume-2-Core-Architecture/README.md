# HTDS Volume 2 — Core Architecture

Volume 2 describes Halcyon's target core architecture.

## Status policy

Each document distinguishes:

- current Tilted Evolution behavior;
- transitional Halcyon behavior;
- target Halcyon architecture;
- unresolved design questions.

No document in this volume should be interpreted as proof that the described system already exists.
